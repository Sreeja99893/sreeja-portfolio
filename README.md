# 🌌 Neon Developer Portfolio

A responsive, high-performance developer portfolio built to showcase modern web engineering projects, technical skills, and research work. Designed with an interactive neon/dark aesthetic, smooth animations, and optimized production builds.

## 🚀 Live Demo
- **Live Preview:** [neon-developer-portfolio--bussasreeja1234.replit.app](https://neon-developer-portfolio--bussasreeja1234.replit.app)

## ✨ Features
- **Interactive UI:** Smooth animations and responsive layout optimized for all screen sizes.
- **Project Showcase:** Highlights key full-stack apps, AI systems, and open-source contributions.
- **Modern Tech Stack:** Engineered with React 19, Vite, Tailwind CSS v4, and TypeScript.
- **Fast Performance:** Lightning-fast static bundling and zero-latency routing.

## 🛠️ Built With
- **Frontend Framework:** React + TypeScript
- **Bundler & Tooling:** Vite
- **Styling:** Tailwind CSS
- **Deployment:** Replit / Vercel
